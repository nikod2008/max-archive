# Архив канала «МаТема» в MAX

Статическая страница-архив: все текстовые посты канала в MAX (10.02–31.10.2026), рубрикатор, поиск и ссылки на посты.

## Что внутри

- `index.html` — готовая страница (один файл, без зависимостей, работает офлайн).

## Как опубликовать на GitHub Pages

### Вариант 1 — отдельный репозиторий

1. github.com → **New repository** → имя `max-archive`, видимость **Public** → Create.
2. **Add file → Upload files** → перетащить `index.html` и `README.md` → **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch** → ветка `main`, папка `/(root)` → **Save**.
4. Через минуту страница будет доступна: `https://<логин>.github.io/max-archive/`.

### Вариант 2 — в существующий репозиторий (например, `igroteka`)

1. Открыть репозиторий → **Add file → Upload files**.
2. Перетащить папку `max-archive` с `index.html` внутри → Commit.
3. Ссылка: `https://<логин>.github.io/igroteka/max-archive/`.

## Как обновлять

1. Открыть `МаТема_Архив_редактор.html` (локально), поправить ссылки/заголовки, добавить или удалить посты.
2. Нажать **«Скачать архив HTML»** — получится новый `МаТема_Архив_MAX.html`.
3. В GitHub: **Add file → Upload files**, перетащить новый файл под именем `index.html` (заменит старый) → Commit.
4. Через минуту страница обновится. Если видите старую версию — обновите с `Ctrl+F5`.

## Заметки

- Страница полностью статическая: ни сервера, ни базы, ни внешних файлов.
- Все данные лежат внутри `index.html` — при обновлении заменяется только он.
- Редактор архива в репозиторий не входит: он нужен только локально для правок.
